Guía explicativa del proyecto

Proyecto: Ciberguerra 2026 — Programación Web I

1. Por qué usé estas etiquetas semánticas

EtiquetaDónde la usé
<header>El título y subtítulo de arriba de todo.
<nav>El menú con los enlaces a cada sección.
<main>Todo el contenido "real" de la página.
<section>Cada bloque: resumen, episodio, ejes, citas, galería, etc.
<article>Cada uno de los 4 ejes temáticos, porque cada uno tiene sentido por sí solo.
<figure> y <figcaption>El video y cada imagen de la galería, junto con su descripción.
<blockquote>Las citas textuales del podcast.
<footer>El pie de página.

Uso <div> solamente para cosas de diseño que no tienen un significado propio, como .contenedor (que solo sirve para centrar el ancho) o .video-wrapper (que solo sirve para el truco del video fluido).

2. Cómo logré que la página sea fluida sin Media Queries, Flexbox ni Grid

2.1 Anchos en porcentaje

En vez de poner anchos fijos en píxeles, uso porcentajes. Por ejemplo, el contenedor principal: 

.contenedor {
  width: 90%;
  max-width: 900px;
  margin: 0 auto;
}

Al usar %, el ancho del contenedor siempre es proporcional al ancho de la pantalla del usuario. El max-width evita que el texto se estire demasiado en pantallas muy grandes.

2.2 inline-block para el menú y la galería

Tanto los enlaces del menú como las imágenes de la galería usan display: inline-block. Esto hace que se acomoden uno al lado del otro, como palabras dentro de una oración. Si no entran todos en una fila, el navegador pasa el que sobra a la fila de abajo automáticamente, sin que yo tenga que escribir ninguna regla especial para pantallas chicas. 

.galeria-item {
  display: inline-block;
  width: 45%;
  margin: 0 2% 20px 0;
}

Como cada imagen mide 45% del ancho y le sumamos un poco de margen, entran 2 por fila en pantallas anchas. En una pantalla angosta (como un celular), ya no entran 2 al lado de la otra, así que se acomodan una debajo de la otra solas.

2.3 Que las imágenes y el video nunca se desborden

Todas las imágenes tienen esta regla, para que nunca sean más anchas que su contenedor: 

img {
  max-width: 100%;
  height: auto;
}

Para el video de YouTube (que es un <iframe>) usé un truco clásico: como el iframe necesita una altura fija, le puse un contenedor por afuera que reserva el espacio correcto usando padding-top: 56.25% (esa cifra sale de dividir 9 entre 16, la proporción de un video 16:9). El iframe de adentro se estira con position: absolute para ocupar todo ese espacio reservado. 

.video-wrapper {
  position: relative;
  width: 100%;
  padding-top: 56.25%;
}
.video-wrapper iframe {
  position: absolute;
  top: 0; left: 0;
  width: 100%;
  height: 100%;
}

3. Resumen

En resumen, toda la adaptabilidad de la página se logra combinando solo tres cosas: porcentajes para que los anchos se recalculen solos, inline-block para que el menú y la galería envuelvan de forma natural, y max-width: 100% en imágenes y video para que nunca se salgan de su contenedor. No usé Flexbox, Grid, Media Queries ni JavaScript en ningún momento.
